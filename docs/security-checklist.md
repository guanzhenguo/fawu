# 上线前安全清单

- 关闭 `DJANGO_DEBUG`，使用密钥管理系统注入随机 `DJANGO_SECRET_KEY`。
- 仅在所有子域长期强制 HTTPS 后开启 `DJANGO_SECURE_HSTS_PRELOAD` 并申请浏览器预加载。
- 接入企业 OIDC/LDAP，停用生产环境 Token 登录或配置短期令牌轮换。
- 为业务、法务、负责人、审计员配置最小权限和数据范围。
- MySQL、对象存储、备份全部启用加密；敏感字段使用信封加密。
- 上传文件校验扩展名、MIME、OOXML 结构、解压体积、宏和恶意内容。
- 原始文件使用私有桶和短期签名 URL，禁止公开访问。
- 文档服务运行在隔离容器，设置 CPU、内存、文件大小与执行超时。
- 审计日志同步到不可变或 WORM 存储，并定期验证哈希链。
- 外部 AI 调用前执行数据分类、最小化、脱敏复检和供应商留存策略检查。
- AI 返回内容必须防提示词注入，且不能直接触发审批通过、签署或付款。
- 对登录、下载、越权、批量导出、审批重放和幂等性执行专项测试。
- 备份恢复演练需要覆盖数据库、对象版本和加密密钥，明确 RPO/RTO。
